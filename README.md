# EverythingAI — Hidden CRM Revenue Calculator

An interactive calculator that estimates how much potential revenue is hidden in a business's CRM.

GitHub Pages serves it straight from `index.html` on the `main` branch. The page is a single
self-contained file: the logo and favicon are embedded, and the only external call is Google Fonts.
To deploy, edit `index.html` and push.

Every "Book My Free Call" button links to the landing page calendar:
https://georgeackers.github.io/everythingai-landing/#calendar

Settings (booking link, cross-link, assumptions) are in the `CONFIG` block near the bottom of `index.html`.
